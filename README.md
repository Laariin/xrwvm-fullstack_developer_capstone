# Best Cars Dealership – Full Stack Developer Capstone

**Repository name:** xrwvm-fullstack_developer_capstone
**Project name:** Best Cars Dealership (Dealership Review Web Application)

A full stack web application for a national car dealership. Users can view dealerships across the US, filter them by state, read reviews with sentiment analysis, and post reviews after logging in.

## Technologies
- **Frontend:** React
- **Backend:** Django (user management, proxy services, CarMake/CarModel)
- **Database API:** Node.js + Express + MongoDB (dealers and reviews)
- **Sentiment analysis:** Flask microservice on IBM Code Engine
- **CI/CD:** GitHub Actions (flake8 + JSHint linting)
- **Deployment:** Docker + Kubernetes
